# 库存管理最佳实践

## 核心指标

| 指标 | 行业标杆 | 计算公式 | 说明 |
|------|----------|----------|------|
| 库存周转率 | 京东：8-10 次/年 | 销售成本/平均库存 | 越高越好 |
| 库存周转天数 | 亚马逊：30 天 | 365/周转率 | 越短越好 |

| 滞销库存占比 | <5% | 滞销 SKU 金额/总库存金额 | 越低越好 |

## 安全库存计算

```
安全库存 = (最大日销量 × 最大供货周期) - (平均日销量 × 平均供货周期)

示例：
- 最大日销量：50 件
- 平均日销量：30 件
- 最大供货周期：15 天
- 平均供货周期：10 天

安全库存 = (50 × 15) - (30 × 10) = 750 - 300 = 450 件
```
