# 电商订单日志设计最佳实践

## 主流平台对比

| 平台 | 日志特点 | 可借鉴点 |
|------|----------|----------|
| 淘宝 | 全链路追踪，16+ 节点 | 状态快照 + 时间戳 |
| 京东 | 物流轨迹实时同步 | 物流节点精细化 |
| 美团 | 到店核销闭环 | 核销码 + 定位校验 |
| 拼多多 | 简化日志，核心 8 节点 | 降低存储成本 |

## 核心日志节点（8 个）

1. 订单创建
2. 订单支付
3. 订单发货
4. 物流运输（多节点）
5. 确认收货
6. 订单完成
7. 售后申请
8. 退款完成

## 设计原则

- **不可篡改**：日志追加写入，不修改历史
- **状态快照**：记录每个节点的单据状态
- **可追溯**：关联单据双向跳转
- **异常标记**：高风险操作高亮显示

## 适用于天工系统

- 销售订单日志：5 个核心节点
- 退货订单日志：5 个核心节点
- 扩展字段用 JSON 存储（定位距离、物流信息等）
