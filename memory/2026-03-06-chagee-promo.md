### 详细组件说明

#### 1️⃣ 导航栏
| 元素 | 说明 |
|------|------|

| 标题 | "购物车" + 商品总数 |
| 管理按钮 | 右上角可切换编辑模式（批量删除） |

#### 2️⃣ 商品卡片
```
┌─────────────────────────────────┐
│ [✓]  ┌───┐                      │
│      │图 │  商品名称标题         │
│      │片 │  ¥199.00             │

│                                 │
│           [-]  2  [+]    🗑     │
```

**字段说明：**
- **复选框**：单选/取消该商品
- **商品图**：100×100px 正方形
- **名称**：最多2行，超出省略
- **价格**：醒目红色/橙色
- **规格**：灰色小字
- **数量控制器**：- / 数字 / +（最小1，最大99/库存）
- **删除**：单个删除图标

#### 3️⃣ 失效商品区（可折叠）
```
┌─────────────────────────────────┐
│  ──── 失效商品 (2)  ⌄ ────      │  ← 点击展开/收起
│  [商品已下架/库存不足]           │
└─────────────────────────────────┘
```

#### 4️⃣ 底部结算栏
```
┌─────────────────────────────────┐
│  ▢ 全选      合计：¥697.00      │
│              [ 结算 (3) ]       │
└─────────────────────────────────┘
```

**交互逻辑：**
- 全选按钮控制所有商品复选框
- 合计金额 = 选中商品单价 × 数量 之和
- 结算按钮显示选中商品数量
- 未选中商品时，结算按钮置灰不可点
