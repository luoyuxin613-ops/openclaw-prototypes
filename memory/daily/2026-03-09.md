## 📚 今日学习：库存管理基础（30 分钟）

### 一、核心概念（10 分钟阅读）

#### 1. 库存类型
```
┌─────────────────────────────────────────┐
│  可用库存 = 实物库存 - 锁定库存 - 残次  │
│  在途库存 = 已采购未入库                │
│  安全库存 = 应对波动的缓冲库存          │
└─────────────────────────────────────────┘
```

#### 2. 关键指标
| 指标 | 公式 | 健康值参考 |
|------|------|-----------|
| 库存周转率 | 销售成本/平均库存 | 电商 6-12 次/年 |
| 周转天数 | 365/周转率 | 30-60 天 |
| 缺货率 | 缺货 SKU 数/总 SKU 数 | <5% |
| 呆滞占比 | 90 天未动销库存/总库存 | <10% |

#### 3. 库存流转逻辑
```
采购入库 → 可用库存↑ → 下单锁定 → 发货扣减 → 售后退回
```

### 二、笨鸟场景应用（10 分钟思考）

**当前问题**：工程师搜不到商品

**库存视角的可能原因**：
1. SKU 属性不完整（缺少搜索索引字段）
2. 库存状态未同步（有货但显示缺货）
3. 类目映射混乱（配件归类错误）

**建议排查顺序**：
```
1. 抽查 10 个搜不到的商品 → 检查 SKU 属性完整性
2. 对比前台显示库存 vs 后台实际库存 → 查同步延迟
3. 统计top50 搜索无结果词 → 反推类目/命名问题
```
